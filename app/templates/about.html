About SentiVision AI

An end-to-end sentiment intelligence platform uniting deep learning NLP with real-time facial expression tracking to decode human emotion across social reviews and camera streams.

Try Text Engine Live Webcam AI
Python & Flask

Production WSGI application factory with Socket.IO websockets and REST API endpoints.

RoBERTa & VADER

HuggingFace Transformers ensemble architecture for social media reviews and slang detection.

OpenCV & FER

Computer vision pipeline detecting faces and calculating 7-expression emotion spectrums in real-time.

MongoDB Layer

High-throughput NoSQL document persistence for analyses, user sessions, and batch jobs.

Platform Capabilities

  • Multi-Model NLP Ensemble: Weighted consensus between CardiffNLP RoBERTa (deep learning), VADER (rule-based), and TextBlob.
  • Live Facial Emotion Recognition: Captures video stream frames via HTML5 canvas, emits over Socket.IO, and overlays live bounding boxes and dominant emotion emojis.
  • Batch Dataset Processing: Ingest CSV, JSON, and Excel review spreadsheets with automated column detection and export capabilities.
  • Webpage Content Scraper: Scrapes online articles, reviews, or Reddit threads and summarizes sentiment distribution.
  • REST API with JWT: Full programmatic integration with access tokens, batch analysis endpoints, and swagger-style documentation.
  • Visual Analytics Reports: Dynamic Chart.js and server-rendered Matplotlib charts with PDF export support.
