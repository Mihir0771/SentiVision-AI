Developer REST API Reference

Programmatic endpoints for text sentiment scoring, facial emotion recognition, and batch jobs

Version 1.0 (v1)
Open API & Base URL

All API requests should be sent to the base URL: http://localhost:5000/api/v1. As an open-source platform, all endpoints are publicly accessible with no mandatory API key or token required!

100% Free & Open Access JSON Responses Sub-50ms Latency
POST /api/v1/auth/token

Generate a JSON Web Token (JWT) valid for 24 hours.

Request Body (JSON):
{
  "username": "demo_user",
  "password": "your_secure_password"
}
cURL Example:
curl -X POST http://localhost:5000/api/v1/auth/token \
  -H "Content-Type: application/json" \
  -d '{"username":"demo_user", "password":"password123"}'
POST /api/v1/analyze/text

Execute multi-model sentiment analysis with RoBERTa, VADER, and TextBlob.

Request Body (JSON):
{
  "text": "The battery performance is phenomenal, but the charging speed could be improved.",
  "models": ["transformer", "vader", "textblob"]
}
Response (200 OK):
{
  "status": "success",
  "data": {
    "sentiment": {
      "overall_sentiment": "positive",
      "overall_confidence": 0.88,
      "ensemble_scores": { "positive": 0.72, "neutral": 0.20, "negative": 0.08 },
      "models": {
        "transformer": { "label": "positive", "confidence": 0.91 },
        "vader": { "compound": 0.63, "label": "positive" },
        "textblob": { "polarity": 0.45, "subjectivity": 0.60, "label": "positive" }
      }
    },
    "keywords": [{ "keyword": "battery performance", "score": 4.5 }],
    "language": { "language": "en", "confidence": 0.99 }
  }
}
cURL Example:
curl -X POST http://localhost:5000/api/v1/analyze/text \
  -H "Content-Type: application/json" \
  -d '{"text": "Incredible camera quality and battery life!"}'
POST /api/v1/analyze/batch

Analyze an array of review or social media texts in bulk.

Request Body (JSON):
{
  "texts": [
    "Amazing product, highly recommend!",
    "It broke after two days, terrible.",
    "Package arrived on time."
  ]
}
POST /api/v1/analyze/image

Detect faces and compute 7-emotion spectrum probabilities from a photo.

cURL Example (Multipart):
curl -X POST http://localhost:5000/api/v1/analyze/image \
  -F "image=@face_photo.jpg"
GET /api/v1/analyses

Retrieve historical sentiment and emotion records for authenticated account.

cURL Example:
curl -X GET "http://localhost:5000/api/v1/analyses?page=1&limit=20" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
GET /api/v1/stats

Get aggregate positive, negative, and neutral percentages and average confidence.
